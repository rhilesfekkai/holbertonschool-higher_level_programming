# Python Object Relational Mapping

This project introduces database access from Python using MySQLdb
and object-relational mapping with SQLAlchemy.

## Task 0: Get all states

The 0-select_states.py script connects to a MySQL database using
command-line credentials, retrieves all rows from the states table
in ascending order by ID, and prints each row as a Python tuple.

## Usage

./0-select_states.py <mysql_username> <mysql_password> <database_name>
